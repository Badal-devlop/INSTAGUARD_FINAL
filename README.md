InstaguardAI is a browser extension that silently monitors Instagram as you scroll, using Google's Gemini AI to analyze posts, reels, and captions for misinformation, manipulated media, and misleading content. Flagged posts receive an inline badge (Likely Fake / Verify This / Satire) with a one-click fact-check panel showing confidence score, reasoning, and sources cross-referenced against NewsAPI and India's official PIB fact-check feed. No login required. No data collected. Community reports are stored on Polygon testnet for decentralized trust. Built for HacKSphere Hackathon 2026
