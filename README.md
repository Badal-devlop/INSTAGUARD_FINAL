# InstaGuard AI

A Chrome extension that helps users identify misinformation, fake news, and potentially AI-generated content on Instagram.

## What it does

While browsing Instagram, InstaGuard AI analyzes posts, reels, and captions and provides a credibility assessment based on:

- Gemini AI analysis
- NewsAPI verification
- PIB Fact Check references
- Community reports

Posts can be marked as:

- ✅ Likely True
- ⚠️ Verify
- ❌ Potentially Misleading

Users can view supporting evidence and fact-check results directly from the extension.

## Features

- Real-time Instagram content analysis
- AI-powered claim verification
- Fact-checking using trusted sources
- Simple credibility badges
- Community reporting system
- Privacy-friendly (no login required)

## Installation

1. Clone the repository

```bash
git clone https://github.com/Badal-devlop/INSTAGUARD_FINAL.git
```

2. Open Chrome and go to:

```
chrome://extensions
```

3. Enable **Developer Mode**

4. Click **Load Unpacked**

5. Select the project folder
